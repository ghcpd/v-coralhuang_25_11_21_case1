# Debug To-Do List

This project provides a small React To-Do List component with fixes and tests.

Purpose
- Demonstrate fixes for common React state bugs: prevent empty tasks, avoid state mutation, and add keys.

Setup
1. Run: ./setup.sh
2. Run tests: npm run verify

Usage
- Open the component `src/DebugToDoList.tsx` and use it in your React application.

Testing
- Tests are located at `__tests__/DebugToDoList.test.tsx`.
- One-command execution: `npm run verify`.

Known issues
- This is a minimal demo for test and validation purposes.
