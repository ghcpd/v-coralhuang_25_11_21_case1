# locate the PID using port 3000
lsof -i :3000

Once the port is free, run yarn dev again and it will boot normally on localhost:3000.

windows how to kill


On Windows you have two easy options:

Command Prompt/PowerShell: netstat -ano | find ":3000" shows the PID using port 3000. Then taskkill /PID <pid> /F terminates it (replace <pid> with the number you saw).
Task Manager: open it, go to the “Details” tab, sort by PID, select the matching process, and click “End task”.
Free up the port this way, then rerun yarn dev.
